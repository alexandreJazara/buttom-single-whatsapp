### 🇧🇷 Português  
Antes de usar, **edite os parâmetros do script JS** para incluir os dados de contato corretos.  
Você pode modificar:  

- 📞 **Número de telefone**  
- 💬 **Mensagem de atendimento pré-definida**

📌 *Certifique-se de atualizar essas informações antes de usar o código!*
